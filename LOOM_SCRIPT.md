# Loom video script (target: 3–4 minutes)

**0:00–0:30 — Problem:** BIAI receives enquiries across WhatsApp, Facebook, the website and phone. Without one place to track them, follow-ups can be missed.

**0:30–1:10 — Dashboard:** Show 20 sample enquiries, source chart and the five pipeline stages.

**1:10–2:00 — Message assistant:** Open a supplied sample message. Demonstrate Extract fields, explain whether the result is from the OpenAI API or the rule-based fallback. Then click Suggest a reply and explain that it avoids inventing fees or dates.

**2:00–2:45 — Workflow:** Open Enquiries, change one status to Interested, save and show the dashboard updating.

**2:45–3:20 — Follow-up:** Show the 48-hour monitor and explain why the historical sample dates produce overdue warnings.

**3:20–4:00 — Trade-offs:** Mention local CSV storage, lack of authentication and messaging integrations; propose a database and secure API integration as next steps.

**Important:** Show real working behavior. Never describe fallback templates as LLM-generated. Keep the recording under five minutes.
